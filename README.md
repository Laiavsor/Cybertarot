# CYBERTAROT // НЕОНОВЫЙ ОРАКУЛ

Таро в стиле киберпанк: неоновый терминал-оракул нового города.
Старшие арканы — те же архетипы, но пропущенные через sprawl.
Младшие масти заменены, чтобы город узнавался с первого взгляда:

| Классика   | CyberTarot        | Значение |
|------------|-------------------|----------|
| Мечи ⚔      | **SWORDS / Мечи** — монолезвия | разум · правда · конфликт |
| Кубки 🏆    | **BANKS / Банки** — энергетики | чувства · страсть · импульс |
| Посохи 🪄   | **WIRES / Провода** — проводники | воля · энергия · действие |
| Пентакли ⬟  | **NUYEN / Ньюены** — крипто-валюта | материя · ценность · труд |

Описания карт — на русском. Текст на картах — английский.

## Что внутри

- **78 карт** с полными толкованиями на русском (прямая/перевёрнутая позиция, ключевые слова).
- **22 старших аркана** — нейро-иллюстрации в нео-нуаре «Бегущего по лезвию» (объёмный неон, хром, дождь, стильные молодые персонажи): `public/cards/major/*.jpg`.
- **56 младших** — процедурный SVG (классические pip-раскладки, киберпанк-эмблемы: монолезвие, энергобанка, катушка провода, чип-ньюен).
- **3 расклада**: «Быстрый хак» (1 карта), «Нейролинк» (3 карты), «Полный дамп» — Кельтский крест (10 карт).
- Сдача из колоды с **глитч-анимацией**, звук через WebAudio, CRT-оверлей (сканлайны, шум, виньетка).
- **Библиотека** всех карт, **лог раскладов** (localStorage), экспорт в буфер / share.
- **PWA**: устанавливается на главный экран Android/iOS, работает офлайн.

## Сборка APK (Capacitor)

Приложение — PWA, и Unity Hub **не собирает** веб-приложения: Unity собирает только проекты на Unity.
Правильный путь до APK без переписывания на C#:

Нативная заготовка уже в репозитории (`android/`, Capacitor 6). Порядок на твоей машине:

```bash
git clone <repo> && git checkout arena/99eb7b02-cybertarot
npm install
npm run build && npx cap sync android
```

Затем папку `android/` открыть в **Android Studio** → `Build → Build APK(s)` → `app/build/outputs/apk/debug/app-debug.apk`.
Понадобятся Android Studio + SDK (бесплатно с developer.android.com).
`capacitor.config.ts` уже в репозитории: `appId city.cybertarot.app`, `webDir: dist`.
Скопированные веб-ассеты и build-артефакты в `android/` намеренно в .gitignore.

Если позже появится желание перенести игру в **Unity** — это отдельный проект (C#), скафолдинг и ассеты (те же 22 аркана-картинки) переносятся как есть.

## Структура

```
src/
  data/cards.ts       — колода: 78 карт, масти, толкования
  data/spreads.ts     — расклады и позиции
  lib/interpret.ts    — офлайн-синтез толкования («сводка системы»)
  lib/sfx.ts          — WebAudio-звук, без файлов
  lib/storage.ts      — лог раскладов и настройки (localStorage)
  components/          — BootScreen, MainMenu, Table, ReadingResult,
                         CardFace, MinorArt (SVG-pip ядро), CardBack,
                         CardDetail, Library, History
public/
  cards/major/        — нейро-арт старших арканов
  icons/              — PWA-иконки
  sw.js               — офлайн-кэш (stale-while-revalidate)
capacitor.config.ts   — конфиг для сборки APK
```

## Идеи на развитие

- Достроить младшие арканы до «нейро»-качества (22/22 старшие уже есть).
- Ещё расклады: «Отношения», «Контракт», «Да/Нет».
- Ежедневная карта дня с пуш-уведомлением (через Capacitor Local Notifications).
- Экспорт расклада картинкой (canvas → png).
